Last updated: October 2026

Bison is an internal tool that only accesses data belonging to Pages the operator's own Business Portfolio owns - it does not collect or store data about individual end users.

If you would like any data associated with a Page that Bison has accessed (published content records, performance-insight snapshots) to be deleted, please contact the operator directly:

Include the Page name and/or Page ID in your request. Deletion requests are processed within a reasonable time of being received.
